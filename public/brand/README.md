- Organiser: Empower with Hafsat

The official Empower with Hafsat / From Girlhood to Greatness event logo was not present in the reconciled repository source. Keep the current typographic wordmark until the organiser supplies the approved asset. Do not create a substitute logo or use unrelated legacy marks.

Existing ISEYC SVG assets are retained for other repository materials and are not automatically placed on the event landing page.
